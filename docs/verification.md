# 验收指南

## 自动隔离检查

- `npm run check`：语法、公开身份、个人路径和凭据样式、标签版本一致性。
- `checks/install-smoke.py`：临时 HOME 中模拟外部安装工具，执行真实配置生命周期：预览、应用、重复安装、保留用户 hooks、旧 hooks 迁移、冲突停止、增量卸载与恢复。
- `checks/exit-smoke.cjs`：使用真实扩展桥接模块、Python 通知桥及模拟系统通知命令，验证历史会话、当前/后台终端退出、幂等和跨窗口共享会话保护。
- `checks/completion-smoke.py`：使用真实完成回调入口、临时数据库和会话文件、通知命令替身，验证未识别会话过滤、原回调转发、耗时匹配与延迟落盘、故障兜底、前台静默和诊断日志。
- `checks/package-smoke.py`：核对 VSIX 文件、版本与身份、agent 依赖许可、校验和和解压路径安全，并从解压工具包执行安装预览。

这些是流程验收，不依赖真实模型、API 密钥或系统通知权限。

## macOS 桌面验收

使用单独 VS Code user-data-dir、extensions-dir 和临时 CODEX_HOME，不改日常配置。现有 `checks/desktop-focus.py` 与 `checks/desktop-click.py` 保留真实 TUI 验收流程；可通过 `CODEX_SMOKE_CODEX`、`CODEX_SMOKE_NOTIFIER` 指定本机可执行路径；未设置时从 PATH 查找。使用 `.venv/bin/python checks/desktop-focus.py` 和 `.venv/bin/python checks/desktop-click.py` 运行，结果写入忽略的 dist 目录。后台工作使用本机 SSE 模拟服务，不调用模型。

安装并信任 hook 后，检查：

1. 后台完成通知标题为项目与会话名，显示对应耗时及本地时间，没有声音。
2. 触发一问、多问，核对数量；切回正确终端通知消失，其他会话不消失。
3. 当前前台会话完成不弹通知，切到编辑器仍静默；后台会话仍正常通知。
4. 同一个 TUI 切换 A/B，识别跟随标题；点击通知找到正确窗口和终端，空闲目标自动切回且草稿保留。
5. 忙碌、重名、窄面板、不支持版本或焦点变化时停止自动操作，不多发回车或聊天消息。
6. 正常退出、关闭当前终端、关闭后台终端均清理已有通知；同会话在另一终端存活时保留。
7. 窗口重载不清掉所有后台通知；旧通知不冒充新版本点击操作。
8. macOS 选择“提醒”后观察持续显示和返回清理，再实际鼠标点击验证整条回调链。

## 已知边界

强杀、崩溃、应用整体退出时，终端关闭事件可能无法交付；状态过期后恢复普通通知，不保证残留通知立即清理。诊断结果应区分实际桌面验证、模拟命令通过与尚未运行。
